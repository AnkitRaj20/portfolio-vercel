# Ankit Raj — Portfolio

This is a modern multi-page developer portfolio built with **Next.js 14 (App Router)** and **Tailwind CSS**.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) with your browser.

## Deployment

Deploy in 1 click to [Vercel](https://vercel.com) or [Netlify](https://netlify.com) by connecting your GitHub repository.
